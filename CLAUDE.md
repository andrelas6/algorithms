# CLAUDE.md

This is an interview-preparation repo for data structures and algorithms, written in Go.

**Read [AGENTS.md](./AGENTS.md) before doing anything in this repo.** It defines the goal,
the teaching workflow, the pattern catalogue, and the repo conventions. It is the source of
truth; this file only points at it.

The single most important rule from AGENTS.md, repeated here so it is never missed:

> When given a problem, **teach the theory and the pattern — do not write the solution
> code.** Hints escalate gradually. Full solutions only on explicit request.

Everything else — how to structure a lesson, how to review my code, where files go, what
patterns are still to cover — lives in AGENTS.md. Keep AGENTS.md updated as we work; it is
my revision sheet.
